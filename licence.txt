Definitions

In these Membership Rules, unless the context demands otherwise, the terms defined below will have the corresponding meaning.

Contractor           Means an individual contracted to work on for a Member for a finite period as an alternative to the Member using internal resources.

DTVKit Software      Means either the DTVKit software or any derivative work under copyright law; that is a work containing DTVKit Software or part of it, either Verbatim or with modifications and/or translated into another programming language

Management Office    The permanent administrative staff of DTVKit.

Member               Means a member of DTVKit of any Membership Class excluding Partners.

Licence              The legally binding agreement between DTVKit and our members It defines how the software can be used and distributed, and what responsibilities and restrictions apply to each party.

Operator             An organisation that sources and aggregates TV content, through the creation of broadcast and IP specifications; and the adoption of standards for manufacturers to build and test interoperable products against.

Participant          An individual who is representing a DTVKit Member.

Platform             A semiconductor device containing a processor capable of executing DTVKit Software or its derivatives.

Source Code          Means the preferred form of the DTVKit Software for making modifications to it including the complete source code for all modules in whatever programming language they are supplied, plus any associated interface definition files, data tables, scripts and documentation.

Binary               Fully compiled source code, shipped as either a software library, or part of an executable application.

Sub-Contractor       Means a company contracted to work on for a Member for a finite period as an alternative to the Member using internal resources.

DTVKit Test Suite    An application designed to test the integration of the porting of DTVKit to the linux porting layer.

Partners Member      A Partner Member is a company that wishes to be part of the DTVKit Eco-System, but does not require (or need) access to the source code.
